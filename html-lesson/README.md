# Информатика | Ашық сабақ — интерактивная презентация

Интерактивная веб-презентация для открытого урока «HTML-де кесте құру» (язык презентации — казахский).
15 этапов урока: видео, деление на команды, Plickers, пазл со скрытой темой, интерактивное объяснение
тегов `<table> <tr> <th> <td>`, практические задания с таймерами, табло баллов, рефлексия «Бағдаршам».

Технологии: React + TypeScript + Vite + Tailwind CSS + Motion + Lucide. Шрифты (с казахскими буквами)
и звуки встроены — **после сборки интернет не нужен** (кроме перехода в Plickers).

---

## 1. Быстрый запуск на Windows

1. Один раз установите **Node.js LTS**: https://nodejs.org (кнопка «LTS», установка «Далее → Далее»).
2. Дважды щёлкните **`START.bat`**.
   - При первом запуске он сам выполнит `npm install` (нужен интернет, один раз).
   - Затем соберёт проект и откроет презентацию в браузере: `http://localhost:4173`.
   - **Не закрывайте чёрное окно** во время урока — это локальный сервер.
3. Нажмите **F** (или кнопку ⛶ справа вверху) — полноэкранный режим.

### Без Node.js и без сервера

Папка `dist/` уже содержит собранную презентацию одним файлом.
Дважды щёлкните **`OPEN-OFFLINE.bat`** (или сам файл `dist/index.html`) — она откроется в браузере
без интернета, без сервера и без установки чего-либо.

> Если вы открываете `dist/index.html` напрямую, видео должны лежать в `dist/videos/`
> (см. раздел «Видео»).

### Как подготовить школьный компьютер (без интернета в классе)

* **Вариант А (с Node.js):** дома или там, где есть интернет, один раз запустите `START.bat`
  (появится папка `node_modules`). Скопируйте всю папку `html-lesson` на флешку → на школьный компьютер
  (на нём тоже должен быть установлен Node.js). Дальше `START.bat` работает полностью офлайн.
* **Вариант Б (без Node.js):** скопируйте на школьный компьютер только папку `dist`
  вместе с видео в `dist/videos/` и откройте `dist/index.html` (или `OPEN-OFFLINE.bat`).

Рекомендуемый браузер — **Google Chrome** или **Microsoft Edge**.

## 2. Команды

```bash
npm install      # установка зависимостей (один раз)
npm run dev      # режим разработки с автообновлением (http://localhost:5173)
npm run build    # сборка в папку dist/ (один файл index.html + videos/)
npm run preview  # просмотр собранной версии (http://localhost:4173)
```

## 3. Видео

Положите файлы в папку **`public/videos/`** точно с такими именами:

| Файл | Этап |
|---|---|
| `cyberbullying.mp4` | 2. Психологиялық ахуал (ролик 1:21) |
| `ai-lesson.mp4` | 7. Жасанды интеллект бейнеролигі |
| `teacher.mp4` | 8. Жаңа тақырып — кнопка «Мұғалім бейнесі» (необязательно) |
| `break.mp4` | 11. Сергіту сәті |

После добавления запустите `START.bat` (или `npm run build`) — видео скопируются в `dist/videos/`.
Если вы используете только `dist/`, кладите видео сразу в `dist/videos/`.

* Формат: MP4 (H.264 + AAC) — открывается во всех браузерах.
* Если файла нет, вместо плеера показывается аккуратная заглушка с именем ожидаемого файла
  и кнопкой «Қайта тексеру» (проверить снова).
* Плеер: Play/пауза, перемотка ±10 с, полоса прокрутки, громкость, полноэкранный режим.
  Видео не запускается само — учитель нажимает Play.

## 4. Управление

| Действие | Как |
|---|---|
| Следующий / предыдущий слайд | `→` / `←`, `PageDown` / `PageUp` (пульт-презентер), кнопки «Келесі» / «Алдыңғы» |
| Первый / последний слайд | `Home` / `End` |
| Полный экран | `F` или кнопка ⛶ |
| Панель учителя | `T` или кнопка ▦ (быстрый переход к этапу, настройки, сброс) |
| Звуковые эффекты вкл/выкл | `M` или кнопка 🔊 |
| Закрыть окно (ответ, видео учителя, панель) | `Esc` или ✕ |
| Сенсорная доска | свайп пальцем влево/вправо по пустому месту слайда |

* Нажатия на кнопки, плитки пазла, карточки и баллы **никогда не переключают слайд**.
* Индикатор внизу показывает блоки урока; по любому сегменту можно щёлкнуть.
* Все результаты (пазл, баллы, таймеры, открытые карточки) **сохраняются** при переходе между
  слайдами и даже при перезагрузке страницы.
* Таймеры продолжают идти, если вы ушли на другой слайд; по окончании звучит сигнал
  и появляется уведомление «Уақыт бітті!».

### Сброс перед новым уроком

Панель учителя (`T`) → «Тазалау» → **«Жаңа сабаққа дайындау»** (нажать дважды для подтверждения).
Там же можно отдельно сбросить пазл, баллы, таймеры или отметки Plickers. На многих слайдах есть
своя кнопка ↻ (тоже с подтверждением).

### Жеңіл режим (лёгкий режим)

Если компьютер слабый и анимации «тормозят» — панель учителя → «Жеңіл режим»
(отключает размытие стекла и фоновые анимации).

## 5. Где что менять

| Что | Файл |
|---|---|
| Все тексты слайдов, задания, вопросы, критерии, примеры таблиц | `src/data/lesson.ts` |
| Названия команд, девизы, цвета, иконки | `src/data/teams.ts` |
| Ссылка Plickers, имена видеофайлов, длительность таймеров, имя учителя/школы | `src/config/settings.ts` |
| Порядок слайдов, названия этапов в навигации, цвета фона | `src/config/slides.ts` |
| Цветовая тема | `src/styles/theme.css` |

Ссылку на конкретный тест Plickers можно вставить и без редактирования кода:
панель учителя → «Plickers сілтемесі».

Код и таблица на слайдах генерируются из одних и тех же данных (`src/lib/htmlTable.ts`),
поэтому, изменив пример в `lesson.ts`, вы автоматически получите корректный код и таблицу.

## 6. Структура проекта

```
html-lesson/
├── START.bat / OPEN-OFFLINE.bat   запуск двойным щелчком
├── dist/                          готовая сборка (один файл index.html)
├── public/videos/                 ваши видео
└── src/
    ├── App.tsx                    навигация, клавиатура, свайпы, переходы
    ├── config/                    settings.ts, slides.ts
    ├── data/                      lesson.ts (тексты), teams.ts (команды)
    ├── store/lessonStore.ts       сохранение состояния урока
    ├── lib/                       звуки, генератор HTML-таблиц, утилиты
    ├── components/
    │   ├── layout/                холст 16:9, верхняя панель, прогресс, панель учителя
    │   ├── ui/                    кнопки, заголовки, модальные окна, вкладки
    │   ├── animations/            живой фон, частицы
    │   ├── code/                  подсветка кода, окно редактора/браузера, таблица-превью
    │   ├── video/                 видеоплеер с заглушкой
    │   ├── timer/                 таймеры и уведомление «Уақыт бітті!»
    │   └── tasks/                 критерии оценивания, образец решения
    └── slides/                    15 слайдов (+ puzzle/ — пазл со скрытой темой)
```

Презентация свёрстана на холсте 1920×1080 и пропорционально масштабируется под любой экран
(проверено на 1920×1080 и 1366×768).

## 7. Перед открытым уроком

- [ ] Положить 4 видео в `public/videos/` и запустить `START.bat` (или скопировать в `dist/videos/`).
- [ ] Вставить ссылку на свой тест Plickers (панель учителя или `settings.ts`) и проверить, что в классе есть интернет для Plickers.
- [ ] При желании указать имя учителя и школы в `src/config/settings.ts` (появится на титульном экране).
- [ ] Проверить звук колонок (эффекты можно выключить кнопкой 🔊).
- [ ] Пройти все слайды один раз на компьютере в классе, затем нажать «Жаңа сабаққа дайындау».
- [ ] Распечатать бумажные карточки для деления на 3 команды.
